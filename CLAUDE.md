# Tres Naranjos website

Marketing site for Tres Naranjos Triple Sec (Agave Imports LLC, Puerto Rico). Plain static HTML, CSS and JS, no framework and no build server. Everything in `site/` is published as is by Cloudflare (Workers static assets, configured in `wrangler.jsonc`).

The people asking for changes are usually not developers. They write in Spanish or English and describe what they want to see. Make the change, check it, and explain what changed in plain words.

## Layout

```
site/                    published folder (Cloudflare serves it as is; see wrangler.jsonc)
  index.html             home page
  donde-comprar.html     store finder with the map
  sobre-nosotros.html    "Sobre nosotros" page: photo + FAQ (GENERATED from tools/faq.json; the photo is PHOTO in build_faq.py). Old /preguntas redirects here
  privacidad.html        privacy notice (GENERATED by tools/build_privacy.py; edit the text there, update it when analytics or data handling change)
  404.html               page shown for any address that doesn't exist (GENERATED by tools/build_404.py; wrangler.jsonc not_found_handling)
  recetas/index.html     drinks grid, served at /recetas/ (GENERATED, do not edit by hand). Old /tragos/ links redirect here (_redirects)
  recetas/<slug>.html    one page per drink, served at /recetas/<slug> e.g. /recetas/mezcalita (GENERATED)
  share/<slug>.jpg       WhatsApp share cards, 1200x630 (GENERATED by build_cards.py); share/home.jpg is hand-made. After changing cards, bump the ?v= number on og:image in build_recipes.py so WhatsApp fetches the new image
  _redirects             old /r/A1.html style links -> new addresses (keep these)
  assets/                photos (.webp), video, fonts
  assets/tragos/         drink photos (folder name kept; the pages are /recetas/) 960x1200; assets/tragos/sm/ = 560x560 thumbnails; assets/tragos/ctr2/ = copies of the 6 home-page drink photos with the glass centered and sized alike (desktop drink card); assets/tragos/wide2/ = 760px wide crops of tools/share-src with the glass centered (new folder name when they change, since /assets is cached a year) (used on the home page drink cards on phones)
  sitemap.xml, robots.txt, _headers (cache rules), favicons
tools/
  drinks.json            ALL drink data: slug (the URL name), name, vibe, glass, tags, photo, ingredients, steps, tip (tips are kept but not shown on the site for now)
  config.json            site_url, whatsapp, email (current values, used by the helper scripts)
  tragos_base.html       shared header, footer, age gate and styles for generated pages
  build_recipes.py       builds site/recetas/<slug>.html from drinks.json
  build_tragos.py        builds site/recetas/index.html from drinks.json
  build_faq.py           builds site/sobre-nosotros.html from faq.json (questions + answers, FAQPage schema)
  build_404.py           builds site/404.html (shared header/footer, links from the site root)
  build_privacy.py       builds site/privacidad.html (privacy notice text lives in this script; update it when analytics or forms are added)
  build_cards.py         builds site/share/<slug>.jpg share cards (needs Pillow, numpy)
  share-src/<slug>.jpg   wide version of a drink photo (glass in the left third, empty backdrop on the right). When it exists, that drink's card is the full photo with film grain and only the drink name; otherwise the card is the square photo with tags plus the name on cream. Wide photos are made by extending the site photo in Krea (Nano Banana Pro, 16:9, 2K) with the prompt in the comment at the top of build_cards.py
  set_contact.py         change WhatsApp number or email everywhere
  set_domain.py          change the site address everywhere (links, share cards, sitemap)
  hoist_meta.py          moves title/description/share-preview tags to the top of <head> (builders run it; run by hand after editing index.html or donde-comprar.html)
```

## Common tasks

**Edit a drink or add one**
1. Edit `tools/drinks.json`. Codes go A1..C4; a new drink gets the next code (D1...) and a `slug`: the name in lowercase, no accents, words joined by hyphens ("Paloma de Toronja" -> `paloma-de-toronja`). The slug is the page address, so never change an existing one; if you must, add a 301 line to `site/_redirects`. Amounts are in oz as numbers (1.5, 0.75); `null` for things like "Hielo". Mark the Tres Naranjos line with a third value `1`, for example `[0.5, "Tres Naranjos", 1]`.
2. New drink photo: 960x1200 WebP in `site/assets/tragos/<photo>.webp` plus a 560x560 crop in `site/assets/tragos/sm/<photo>.webp`. Match the existing look: one glass, flat colored backdrop, hard warm sunlight, leaf shadows, film grain.
3. Run, from the repo root:
   `python3 tools/build_recipes.py && python3 tools/build_tragos.py && python3 tools/build_faq.py && python3 tools/build_404.py && python3 tools/build_privacy.py && python3 tools/build_cards.py`
4. Add `/recetas/<slug>` to `site/sitemap.xml`.

Links between pages: generated pages in `site/recetas/` use `<base href="../">`, so write links relative to the site root (`recetas/mezcalita`, `assets/...`). Link to drinks without `.html` (Cloudflare serves `recetas/mezcalita.html` at `/recetas/mezcalita`).

The home page section "Una naranja, mil maneras" shows 6 featured drinks from its own `const RECIPES` block in `site/index.html` (plus `SHARE_CODE` and `SHARE_TAGS` next to it). Keep it in sync with drinks.json when you change one of those 6.

**Change the WhatsApp number or email**
`python3 tools/set_contact.py --whatsapp 1787XXXXXXX` (digits only, starting with 1)
`python3 tools/set_contact.py --email nuevo@correo.com`

**Change the domain** (live domain: https://tresnaranjos.com, on Cloudflare since Oct 2026; tresnaranjoslicor.com forwards to it from GoDaddy)
`python3 tools/set_domain.py https://tresnaranjos.com`, then run the four build scripts. Also lock the Mapbox token to the new domain in the Mapbox account.

**Stores on Dónde comprar**
Only places where you can buy a bottle (supermarkets, cash and carry, liquor stores); no bars or restaurants (Paul, Oct 2026). The list is the `const TIENDAS = [...]` array in `site/donde-comprar.html`: name, type, address, town, phone, "lat, lng" (start with `~` when approximate). It can instead read a published Google Sheet CSV: paste the link into `STORES_CSV_URL` in the same file (instructions are in the comment above it). The home page closing section ("10 lugares en 7 pueblos", its town list and its small map pins) is hand-written in `site/index.html`; update it when the store list changes a lot. The "Disponible en" strip under the hero is also in `site/index.html`.

**Instagram row (home page)**
Live from Behold (free plan: 6 posts, refreshes daily, about 1,200 views a month): `IG_FEED_URL` in `site/index.html` = https://feeds.behold.so/y9Us941u0nkHzeqMUZSs (account in Behold connected to @tresnaranjosoficial). If the feed fails or runs out of views, the hand-picked photos below it in the same script show instead. Once the real domain is live, consider caching the feed through Cloudflare so views never run out.

**Analytics**
Microsoft Clarity (project `z1a9it5war`, account Alfonso's) plus Cloudflare Web Analytics (turned on in the Cloudflare dashboard for tresnaranjos.com, no code). The Clarity snippet sits before `</head>` in `site/index.html`, `site/donde-comprar.html` and `tools/tragos_base.html` and only loads on tresnaranjos.com. It sends click events: whatsapp_agave_imports, whatsapp_ventas, whatsapp_contacto, receta_compartida_whatsapp, copiar_contacto, llamar_agave_imports / llamar_insular, email_agave_imports / email_insular, como_llegar_tienda, clic_donde_comprar, abrir_receta, instagram_post, instagram_perfil. Keep the privacy page in step if tools change.

**Edit the FAQ**
Edit `tools/faq.json` (answers may contain simple HTML links), then run `python3 tools/build_faq.py`.

## Brand rules (keep the site consistent)

- Spanish (Puerto Rico). Orange is "china" in ingredients; "lima" is the green one, "limón" the yellow one. Amounts written "1 1/2 oz", "3/4 oz".
- No em dashes in copy.
- Colors: brand orange #E8561A, buttons #EE5F1C (hover #E04F12), cream #FFF4E6, ink #2D2926, yellow #F7C45A, WhatsApp green #1E8E4F.
- Fonts: El Camino (display and logo), Hanken Grotesk (body and buttons), Courier Prime (small labels, ingredient lists; regular-weight ingredient lines get `-webkit-text-stroke:.4px currentColor` so they read on screen). All self-hosted in `site/assets/fonts/`.
- Buttons are flat pills: no outlines, no hard drop shadows, no animated borders. Hover only makes a button a touch lighter, never darker (one shared rule at the end of each page). Animation is minimal (section headlines fade up once).
- Never invent reviews, testimonials or ratings.
- Keep the designer credit line ("Diseño por Alfonso Rodriguez", class `credit`, linking to https://www.linkedin.com/in/alfonsorodz until his portfolio site exists) at the bottom of every page. It is required by the designer and must not be removed.
- Keep the age gate and "Disfruta con responsabilidad" on every page. The GOVERNMENT WARNING was removed from the footer at Paul's request (Oct 2026).
- Words: the menu says "Recetas" (never "Tragos") and "Sobre nosotros". Tres Naranjos stands on its own: no "Imaginado para Puerto Rico" line and no links or "sister brand" copy for Tres Santos (Paul wants the brands as cousins, not sisters).

## Before finishing any change

- WhatsApp/Google previews: title, description, og: and twitter: tags, canonical and JSON-LD must sit inside <head>, near the top. After hand-editing `site/index.html` or `site/donde-comprar.html`, run `python3 tools/hoist_meta.py site/index.html site/donde-comprar.html`.
- Every push to `main` goes live on Cloudflare in about a minute. Batch related changes into one push.

- Open the changed pages in a browser at phone width (390px) and laptop width (1440px) and check nothing overlaps or spills sideways.
- Check there are no broken images or console errors.
- Images: new photos as WebP, around 80 quality, no wider than 1600px.
- Commit with a short message describing the change. Pushing to `main` deploys to Cloudflare automatically in about a minute.
